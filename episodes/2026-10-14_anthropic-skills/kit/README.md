# 스킬 템플릿 키트 (영상 공개 후 48시간 공개)

다음 키트는 수요일·토요일 롱폼과 함께 올라옵니다. 구독과 알림을 켜 두시면 가장 먼저 받을 수 있어요.

## 들어 있는 것
- [SKILL.template.md](SKILL.template.md): 빈칸만 채우면 되는 SKILL.md 틀
- [make-skill-prompt.md](make-skill-prompt.md): Claude Code에 붙여 넣으면 반복 작업을 스킬로 바꾸는 프롬프트

## 쓰는 법
1. 프로젝트에서 반복하는 일을 하나 고릅니다.
2. `make-skill-prompt.md` 내용을 Claude Code에 붙여 넣고, 맨 위 `[반복하는 일]` 칸만 바꿉니다.
3. 만들어진 폴더를 `.claude/skills/<이름>/` 에 두고, 다음에 같은 일을 시켜 보며 스킬을 불러오는지 확인합니다.

모두 우리 제안이며, 강연 내용(스킬 = 폴더, 이름·설명 먼저 읽기, 스크립트를 도구로)을 따랐습니다.
