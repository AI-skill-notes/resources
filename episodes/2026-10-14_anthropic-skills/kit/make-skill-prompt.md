# 반복 작업을 스킬로 바꾸는 프롬프트 (Claude Code에 그대로 붙여 넣기)

```
[반복하는 일]: 여기에 한 줄로 적기 (예: PR 설명을 우리 팀 형식으로 쓰기)

목표
- 위 반복하는 일을 Claude Code 스킬 폴더 하나로 만든다.

절대 원칙
- 폴더 위치는 .claude/skills/<짧은-영문-이름>/ 로 한다.
- SKILL.md 맨 위 프런트매터에 name 과 description 을 쓰고, description 은 '언제 쓰는지'가 드러나는 한 줄로 쓴다.
- SKILL.md 본문은 짧게 유지하고, 긴 참고 내용은 reference.md 같은 별도 파일로 나눈다.
- 이 대화에서 같은 코드를 두 번 이상 썼다면 그 코드를 scripts/ 안에 저장하고, SKILL.md 에 언제 실행하는지 적는다.
- 내가 확인하지 않은 사실(회사 규칙, 숫자)은 지어내지 말고 빈칸으로 남긴다.

단계
1. 지금 프로젝트에서 이 일과 관련된 파일·명령을 찾아 목록으로 보여 준다.
2. SKILL.md 초안(언제 쓰나 / 순서 / 지킬 것 / 끝났다고 보는 기준)을 만든다.
3. 반복 코드가 있으면 scripts/ 에 저장한다.
4. 새 대화에서 이 일을 시켰을 때 스킬을 불러올 수 있도록 description 한 줄을 다시 다듬는다.

산출물
- .claude/skills/<이름>/SKILL.md (+ 필요하면 reference.md, scripts/)

테스트
- 같은 일을 한 번 더 요청해서 스킬을 불러오는지, 결과가 SKILL.md 의 '끝났다고 보는 기준'을 채우는지 확인하고 결과를 알려 줘.

완료 조건
- 폴더 구조와 SKILL.md 전문을 보여 주고, 테스트 결과(불러왔는지 / 기준을 채웠는지)를 한 줄씩 적는다.
```
