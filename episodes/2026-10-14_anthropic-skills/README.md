# Anthropic 'Don't Build Agents, Build Skills Instead' 풀이: 에이전트는 하나, 전문성은 스킬 폴더로

- 원본 강연(AI Engineer, Barry Zhang · Mahesh Murag, Anthropic): https://www.youtube.com/watch?v=CEvIs9y1uog
- 바로 쓰는 체크리스트: [checklist.md](checklist.md)
- 스킬 템플릿 키트(영상 공개 후 48시간): [kit/](kit/)

## 강연이 말하는 것 (우리 말로 요약)
1. **에이전트는 하나면 된다**: 분야마다 에이전트를 따로 만들 줄 알았지만, 코드가 디지털 세상의 공통 입구라서 파일을 읽고 쓰고 코드를 실행하는 에이전트 하나(Claude Code)가 범용 에이전트였다. 모자란 것은 그 분야의 전문성이다.
2. **스킬은 그냥 폴더다**: 작업 순서 지식을 파일로 묶은 것. Git으로 버전을 관리하고, 압축해서 팀과 나눈다.
3. **스크립트를 도구로**: Claude가 같은 파이썬 스크립트를 반복해서 쓰자, 그 스크립트를 스킬 안에 저장하게 했다. 그다음부터는 실행만 하니 결과가 일정해졌다.
4. **필요할 때만 읽는다**: 처음에는 스킬의 이름과 설명만 보이고, 필요할 때 SKILL.md 본문, 그다음 다른 파일을 읽는다. 그래서 스킬 수백 개를 함께 둘 수 있다.
- MCP는 바깥 세상과의 연결, 스킬은 그 연결을 활용하는 전문성이다.
- 스킬도 소프트웨어처럼 시험(제때 불러오는지·결과 품질)과 버전 기록이 필요하다.
- Claude는 skill-creator 스킬로 스킬을 직접 만들 수 있다.
