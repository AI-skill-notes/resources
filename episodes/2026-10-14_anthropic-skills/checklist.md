# 에이전트 대신 스킬 만들기 체크리스트

구조는 강연(Anthropic)의 말, 세부 문장은 우리 제안입니다.

- [ ] **에이전트 하나**: 새 에이전트를 만들기 전에, 지금 쓰는 Claude Code에 그 일을 먼저 맡겨 본다
- [ ] **스킬 폴더**: 자주 반복하는 일 하나를 골라 폴더를 만들고 `SKILL.md`를 둔다
- [ ] `SKILL.md` 맨 위 설명 한 줄에 '언제 쓰는 스킬인지'를 적는다 (이 한 줄을 보고 Claude가 꺼내 쓴다)
- [ ] **스크립트 저장**: Claude가 같은 스크립트를 두 번 쓰면 이렇게 말한다
  > 방금 쓴 스크립트를 이 스킬 폴더 안에 저장하고, SKILL.md에 언제 쓰는지 한 줄 적어 줘
- [ ] **필요할 때만 읽기**: 긴 참고 자료는 `SKILL.md`에 다 넣지 말고 폴더 안 다른 파일로 나눈다
- [ ] skill-creator에게 초안을 맡긴 뒤 두 가지를 확인한다
  - [ ] 필요한 순간에 스킬을 불러오는가
  - [ ] 스킬을 쓴 결과가 기대한 수준인가
- [ ] 스킬을 바꿀 때마다 무엇을 왜 바꿨는지 기록한다 (Git 커밋이면 충분)

## 폴더 예시 (우리 정리)
```
my-skill/
├ SKILL.md        언제, 어떻게 쓰는지
├ reference.md    참고 문서 (필요할 때만 읽힘)
└ scripts/        반복 작업 스크립트
```
