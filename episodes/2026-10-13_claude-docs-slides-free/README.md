# Claude Docs·Slides·Design 정식 출시: 무료 요금제에서도 발표 자료 만들기

- 원본(Anthropic 공식 글, 2026-10-08): https://claude.com/resources/articles/dashboards-and-motion
- 바로 쓰는 체크리스트: [checklist.md](checklist.md)

## 공식 글이 말하는 것 (우리 말로 요약)
- Claude Docs, Slides, Design이 베타를 마치고 **무료를 포함한 모든 요금제**에서 쓸 수 있게 됐다.
- 공식 글 기준으로 지금까지 Claude에서 만든 문서·발표 자료·디자인은 4,500만 개가 넘는다.
- PowerPoint·PDF로 내려받으면 편집기에서 만든 모양 그대로 나오고, 발표 자료는 Google Slides에 고칠 수 있는 파일로 바로 보낼 수 있다.
- 휴대폰 Claude 앱에서도 문서·발표 자료·디자인을 고칠 수 있다.
- 따로 있던 claude.ai/design 사이트는 Claude 안으로 합쳐지고, 12월 14일까지만 열려 있다.

## 함께 발표된 것 (무료 아님)
| 기능 | 하는 일 | 쓸 수 있는 요금제 |
|---|---|---|
| Claude Dashboards | BigQuery·Databricks·Snowflake 같은 데이터 플랫폼이나 Salesforce에 연결해 계속 갱신되는 대시보드 만들기 | 유료 요금제 베타 |
| Claude Motion | 발표용 짧은 애니메이션 설명 만들기 | Team·Enterprise 베타 |

Enterprise 관리자라면: Dashboards와 Motion은 기본으로 꺼져 있고(조직 설정 > Artifacts), Docs·Slides·Design은 10월 15일부터 기본으로 켜집니다.
