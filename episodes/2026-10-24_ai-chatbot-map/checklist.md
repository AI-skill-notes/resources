# AI 챗봇 아키텍처 지도 체크리스트 (AI스킬노트)

서버 한 대에서 사용자 100만 명 규모까지, 막힐 때마다 더하는 상자 여덟 개를 오늘 확인할 일로 옮긴 목록이에요.

- [ ] 막히면 먼저 무엇이 기다리는지 본다
- [ ] 상자는 막힌 문제가 생길 때 하나씩 더한다
- [ ] AI 한도 앞에는 대기열과 재시도 규칙을 둔다
- [ ] 서버 메모리에 대화를 남기지 않는다
- [ ] 샤딩은 복제본과 캐시로 버틸 수 없을 때

정거장: 서버 한 대 → DB 분리 → 서버 여러 대 → 캐시 → 대기열과 한도 → DB 복제와 샤딩 → CDN → 모니터링
