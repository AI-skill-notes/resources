# 지우기부터 검증까지 4단계 체크리스트 (복사해서 쓰세요)

새 모델이 나왔을 때, 또는 6개월에 한 번 해 보세요.

## 1. 지우기
- [ ] `CLAUDE.md`, 스킬, 훅을 지우지 말고 다른 폴더로 옮겨 둔다 (언제든 되돌릴 수 있게)

## 2. 써 보기
- [ ] 무엇이 필요할지 짐작하지 않고, 평소 하던 일을 그대로 맡긴다
- [ ] 잘하는 곳과 막히는 곳을 메모한다

## 3. 되돌리기
- [ ] 같은 곳에서 두 번 넘게 막힐 때만, 그 지시를 한 줄씩 다시 넣는다
- [ ] 모델은 지시문을 매번 읽는다: 필요 없는 줄은 다시 넣지 않는다

## 4. 어렵게 맡기고 검증
- [ ] 하나하나 순서를 지시하지 않고, 아래 틀로 맡긴다

```
할 일: ...
지킬 선: ...
끝 기준(완료 조건): ...
확인 방법: (예) 테스트 실행, 원래 화면과 비교
```

- [ ] 예전 모델이 못 한 일도 새 모델에게 다시 맡겨 본다
