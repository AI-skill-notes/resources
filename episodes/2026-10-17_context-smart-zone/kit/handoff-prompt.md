# 인수인계 프롬프트 (큰 작업을 새 세션으로 넘길 때)

## 1. 지금 세션에서 붙여 넣기
```
지금까지의 작업을 새 세션에서 이어 갈 수 있게 HANDOFF.md 파일 하나로 정리해 줘.
다음 네 부분으로 나눠서 써 줘.
1. 목표: 이 작업이 끝나면 무엇이 되어 있어야 하는지 한 줄
2. 정한 것: 지금까지 결정한 내용과 그 이유
3. 남은 일: 다음에 할 일을 순서대로, 각각 끝났는지 확인하는 방법과 함께
4. 건드리면 안 되는 것: 바꾸면 안 되는 파일 · 설정 · 규칙
추측은 쓰지 말고, 확인한 것만 적어 줘.
```

## 2. 새 세션에서 첫 메시지
```
HANDOFF.md를 먼저 읽고, '남은 일'의 첫 번째부터 이어서 해 줘.
'건드리면 안 되는 것'은 바꾸지 마.
```

## 언제 쓰나요
- 작업이 하루를 넘기거나, 한 세션에서 다 끝내기 어려울 만큼 클 때
- `/context` 숫자가 내가 정한 선을 넘었는데 같은 일을 계속해야 할 때

(문서로 나눠 진행하라는 방향은 공식 문서, 프롬프트 문장은 우리 제안입니다.)
