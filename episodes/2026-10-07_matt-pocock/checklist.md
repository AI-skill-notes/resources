# 5단계 적용 체크리스트 (복사해서 쓰세요)

작은 일 하나로 먼저 돌려 보세요.

## 시작 전
- [ ] 스킬 파일을 직접 읽어 본다
- [ ] 설치 뒤 `/context`로 스킬이 차지하는 양부터 확인한다

## 5단계
- [ ] ① 질문 `/grill-with-docs`: 바꾸고 싶은 일 하나를 던진다. 질문마다 '네'만 누르지 말고 내 답의 이유를 적는다
- [ ] ② 스펙 `/to-spec`: 논의를 문서 하나로 압축한다
- [ ] ③ 티켓 `/to-tickets`: 세션 하나 크기의 조각으로 쪼갠다
- [ ] ④ 구현 `/implement`: `/clear`로 비운 뒤 티켓을 한 장씩 처리하고, 티켓 사이마다 컨텍스트를 비운다
- [ ] ⑤ 리뷰 `code-review`: 코드를 쓴 에이전트가 아니라 새 서브 에이전트에게 맡기고, 스펙 조건 하나하나와 저장소 표준에 대조한다

## 오늘 가져갈 것 (영상 마지막 화면과 같아요)
- 질문부터 받기 · `/grill-with-docs`
- 스펙 → 티켓 · 티켓 하나 = 세션 하나
- 리뷰는 새 에이전트에게
