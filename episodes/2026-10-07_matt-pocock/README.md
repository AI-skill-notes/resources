# Matt Pocock이 직접 보여 준 AI 코딩 5단계 순서: 질문부터 리뷰까지

- 영상: https://youtu.be/7G2KNv_z8ec (2026-10-07 공개)
- 다룬 스킬 저장소: https://github.com/mattpocock/skills
- 바로 쓰는 체크리스트: [checklist.md](checklist.md)

## 요약
큰 작업을 AI에게 맡기기 전에, 먼저 AI가 나에게 질문하게 합니다. 그 답을 스펙 문서 하나로 모으고, 세션 하나에 끝나는 티켓으로 나눈 뒤, 티켓을 한 장씩 구현합니다. 마지막 리뷰는 코드를 쓴 에이전트가 아니라 새 에이전트에게 맡깁니다.

## 설치
```
npx skills@latest add mattpocock/skills
```
Node.js가 필요합니다(저장소 README 기준). 설치하기 전에 스킬 파일을 직접 읽어 보세요.

## 출처
연사의 말은 옮겨 싣지 않고 우리 말로 요약했습니다. 단계 순서는 연사가 영상에서 보여 준 순서이고, 체크리스트의 세부 문장은 우리 제안입니다.
