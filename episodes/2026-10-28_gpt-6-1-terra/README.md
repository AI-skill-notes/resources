# OpenAI 새 모델 GPT-6.1 Terra: 공식 글 정리와 작업당 비용 계산표

- 영상(AI스킬노트 쇼츠, 10월 28일 아침 7시 공개): 공개 뒤 이 줄에 주소를 붙여요.
- 출처: OpenAI 'Introducing GPT-6.1 Terra' https://openai.com/index/introducing-gpt-6-1-terra/ (2026-10-27 확인)
- Claude Opus 5.5 가격: Claude 공식 문서 'Claude Opus 5.5' https://platform.claude.com/docs/en/models/opus-5-5/overview (2026-10-13 확인)
- 정리한 날: 2026-10-27. 아래 숫자는 모두 공식 글에 적힌 값을 우리 말로 옮긴 거예요. 우리가 직접 잰 값은 없어요. 광고·협찬 아님.

## 어디서 쓸 수 있나요
- ChatGPT의 Plus, Pro, Enterprise, Edu 사용자(ChatGPT Work와 Codex). 무료 요금제는 아니에요.
- API 모델 이름: `gpt-6.1-terra`
- API 가격(100만 토큰당): 입력 1달러, 캐시 입력 0.05달러, 출력 5달러.
- 비교: Claude Opus 5.5는 100만 토큰당 입력 4달러, 출력 20달러예요(Claude 공식 문서).

## OpenAI가 말한 숫자와, 그 숫자가 빼고 잰 것
| OpenAI 공식 글 | 빼고 잰 것·같이 볼 것 |
|---|---|
| 가장 높은 추론 설정에서 Terra는 Claude Opus 5.5보다 토큰을 3배 넘게 적게 쓰고, 토큰 값은 4분의 1이라 작업당 비용이 약 9배 낮다 | OpenAI가 직접 잰 값이에요. 시험은 컴퓨터 작업 시험(Agents' Last Exam) 하나예요 |
| Terminal-Bench 4.0에서 문제의 50.3%를 풀었다(이전 GPT-5.6 Terra 21.5%) | 가장 어려운 코딩에는 GPT-6.1 Sol과 GPT-6 Astra가 낫다고 OpenAI도 적었어요 |
| API 가격이 GPT-5.6 Terra, GPT-6.1 Sol보다 50% 낮다 | 같은 일을 할 때 쓰는 토큰 수는 작업마다 달라요 |

## 작업당 비용 계산표 (내 작업으로 직접 비교하기)
작업 하나에 드는 돈 = (입력 토큰 수 × 입력 가격 + 출력 토큰 수 × 출력 가격) ÷ 1,000,000

- [ ] 내가 자주 시키는 작업 하나를 고른다(예: 메일 요약, 코드 리뷰 한 건).
- [ ] 두 모델에 같은 작업을 시키고, 응답에 나오는 사용량(입력 토큰·출력 토큰)을 적는다.
- [ ] 위 식에 각 모델 가격을 넣어 작업 하나당 비용을 계산한다.
- [ ] 결과가 쓸 만한지도 같이 본다. 싼데 다시 시켜야 하면 그 비용도 더한다.
- [ ] 토큰 가격표만 보고 고르지 않는다. 토큰 값이 싸도 많이 쓰면 비싸지고, 비싸도 적게 쓰면 쌀 수 있어요.

새 모델이 나오면 다시 확인한 결과를 이 저장소에 올려요. 놓치지 않으려면 AI스킬노트를 구독해 두세요.
