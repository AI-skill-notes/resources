# Claude 자동 모드가 기본값이 돼요: 공식 안내 정리와 모드 바꾸는 법

- 영상(AI스킬노트 쇼츠, 10월 25일 아침 7시 공개): 공개 뒤 이 줄에 주소를 붙여요.
- 출처: Anthropic 'Auto mode default in Claude Code'(claude.com, 2026년 8월 7일 글, 10월 22일 업데이트) https://claude.com/resources/articles/auto-mode-default-in-claude-code
- 정리한 날: 2026-10-24. 아래 내용은 공식 글 문장을 우리 말로 옮긴 거예요. 광고·협찬 아님.

## 무엇이 바뀌나요
- 10월 22일 업데이트에 따르면, 다음 주부터 Pro·Max·Team 요금제의 Claude 앱 대부분에서 새로 여는 대화는 자동 모드가 기본이 돼요.
- 자동 모드에서는 Claude가 하나하나 묻는 대신, 자동 검사가 하려는 일을 먼저 봐요. 안전한 일은 진행하고, 위험한 일은 막은 뒤 Claude가 다른 방법을 찾아요.
- Enterprise 관리자는 자동 모드가 기본이 되기 전에 이메일 안내를 받아요.
- Claude Code에서는 이미 8월 14일부터 Pro·Max·Team 요금제의 새 대화가 자동 모드로 시작했어요.

## 왜 바꾸나요 (공식 글 숫자, 모두 Claude Code 자료)
- Claude Code 사용자는 권한을 묻는 창의 97%를 허용했어요. 하나하나 살피기보다 습관처럼 누르는 경우가 많다는 뜻으로 설명해요.
- 유료 테스터 1,053명이 참여한 시험에서, 위험한 명령을 사람은 13.6%만 막았고 자동 모드는 89%를 막았어요.
- 다만 공식 글도 자동 모드가 분류 시스템에 기대기 때문에 위험을 없애 주지는 않는다고 적었어요. 실제 서비스 서버처럼 중요한 곳을 바꿀 때는 Claude가 하는 일을 직접 확인하라고 권해요.

## 체크리스트: 중요한 작업 전에
- [ ] Claude Code(터미널)에서는 `Shift+Tab`을 눌러 모드를 바꿀 수 있어요.
- [ ] 데스크톱 앱에서는 모드 메뉴(드롭다운)에서 바꿀 수 있어요.
- [ ] (Claude Code 기준) 이미 다른 기본 모드를 직접 정해 둔 사람은 한 번 '자동 모드로 바꿀지' 묻는 창을 볼 수 있어요. 기본 모드를 고정해 두었다면 바뀌지 않아요.
- [ ] 회사 관리자는 관리 설정의 `defaultMode`로 조직 기본값을 정하거나, `disableAutoMode`로 자동 모드를 끌 수 있어요.
- [ ] 배포·데이터 삭제·결제처럼 되돌리기 어려운 작업은 모드를 바꿔서 한 단계씩 직접 확인해요.
