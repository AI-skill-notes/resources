# AI스킬노트 자료실

유튜브 채널 **AI스킬노트**([@ai스킬노트](https://www.youtube.com/@ai스킬노트))의 무료 자료실입니다.

AI 개발 도구를 먼저 써 보고 재 본 뒤, 바로 쓸 수 있는 파일로 정리해 둡니다. 가입이나 신청은 필요 없습니다. 필요한 파일을 그대로 복사해서 쓰시면 됩니다.

## 올라오는 자료
- 영상에서 쓴 **프롬프트**와 **설정 파일**(`CLAUDE.md`, 스킬 파일 등)
- 따라 하기 쉬운 **체크리스트**
- 우리가 직접 잰 **측정 결과**(어떤 조건에서 쟀는지 함께 적습니다)

새 모델이 나와서 결과가 달라지면 자료를 다시 재서 고칩니다. 고친 내역은 각 폴더의 `CHANGELOG`에 남깁니다.

## 폴더 구조
```
episodes/
  <날짜>_<주제>/             # 자료 하나 = 폴더 하나
    README.md                 # 영상 링크, 원본 출처, 요약
    checklist.md              # 바로 쓰는 체크리스트
```
